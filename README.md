# مختبر الأمان السيبراني
## Arabic Cybersecurity Testing Lab

مستودع عربي متخصص في **توثيق واختبار الأمان السيبراني** بطريقة عملية وآمنة في بيئات مختبرية معزولة.

يهدف هذا المشروع إلى:
- 📚 **التثقيف الأمني**: شرح مفصل لآليات الهجمات والثغرات الأمنية
- 🛡️ **بناء الوعي الدفاعي**: توضيح كيفية الحماية والتصدي للتهديدات
- 🔬 **الاختبار العملي**: خطوات تطبيقية في بيئة محكومة وآمنة
- ⚖️ **الالتزام القانوني**: التأكيد على الاستخدام المأذون والقانوني فقط

## ⚠️ تنبيه قانوني وأخلاقي

جميع الاختبارات الموثقة هنا:
- **للأغراض التعليمية والدفاعية فقط**
- **يجب تنفيذها في بيئات مختبرية معزولة**
- **تتطلب موافقة كتابية صريحة من جميع الأطراف**
- **استخدام غير مرخص قد يكون مخالفاً للقانون**

## 🚀 البدء السريع

- نظام Linux (Kali Linux, Ubuntu, Debian)
- صلاحيات جذر (sudo/root)
- إتصال إنترنت مستقر
- جهاز أو جهاز افتراضي للاختبار

```bash

cd cybersecurity-lab
```

### الخطوة 2: اختر الاختبار الذي تريده

اقرأ الملف المناسب من مجلد `network-tests/` واتبع الخطوات بحذر وانتباه

### الخطوة 3: نفّذ في بيئة معزولة آمنة

استخدم أجهزة افتراضية (VirtualBox, KVM, VMware) أو شبكة اختبار معزولة

## 📋 الاختبارات المتاحة

### 1️⃣ اختبار ARP Spoofing و MITM
**الملف:** `network-tests/01-arp-spoofing-mitm-lab.md`

يوضح كيفية:
- تنفيذ هجوم ARP Spoofing في الشبكة المحلية
- إنشاء وضعية Man-in-the-Middle (MITM)
- اعتراض البيانات باستخدام Wireshark
- استعادة الحالة الطبيعية بأماناً

**الأدوات:** `arp-scan`, `arpspoof`, `Wireshark`

**المدة:** 30-45 دقيقة

### 2️⃣ اختبار تحديد الموقع الجغرافي والهندسة الاجتماعية
**الملف:** `network-tests/02-geolocation-social-engineering-lab.md`

يوضح كيفية:
- إنشاء صفحات هبوط مزيفة مقنعة
- جمع بيانات الموقع الجغرافي الدقيق
- الحصول على معلومات الجهاز والمتصفح
- جمع بيانات ISP وعنوان IP العام

**الأدوات:** `Seeker`, `ngrok`, `Python 3`

**المدة:** 20-30 دقيقة
