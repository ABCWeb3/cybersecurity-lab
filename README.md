# مختبر الأمن السيبراني

## Arabic Cybersecurity Testing Lab

مستودع عربي لتوثيق اختبارات الأمن السيبراني بطريقة عملية وآمنة داخل بيئات مختبرية محكومة.

يهدف المشروع إلى:

- شرح آليات الهجمات والثغرات بصورة مفهومة.
- بناء الوعي الدفاعي وشرح وسائل الكشف والحماية.
- توفير خطوات قابلة لإعادة الاختبار مع نتائج متوقعة واضحة.
- ترسيخ الاستخدام القانوني والمأذون وحماية بيانات المشاركين.

## تنبيه قانوني وأخلاقي

> [!CAUTION]
> نفّذ الاختبارات فقط على أجهزة وشبكات تملكها أو لديك تصريح مكتوب لاختبارها. استخدم بيانات تجريبية، ولا تجمع أو تحتفظ ببيانات أشخاص آخرين. قد يكون الاستخدام غير المصرح به مخالفًا للقانون.

كل اختبار في هذا المستودع يفترض ما يأتي:

- مختبر منفصل عن شبكة المنزل أو العمل والإنتاج.
- موافقة صريحة من جميع المشاركين.
- عدم استخدام حسابات أو كلمات مرور أو مواقع حقيقية.
- إيقاف الأدوات وحذف المخرجات الحساسة بعد انتهاء الاختبار.

## البدء السريع

### 1. نسخ المستودع

```bash
git clone https://github.com/ABCWeb3/cybersecurity-lab.git
cd cybersecurity-lab
```

### 2. اختيار الاختبار

افتح ملف الاختبار المطلوب واقرأه كاملًا، خصوصًا أقسام المتطلبات وحدود النطاق والتنظيف.

### 3. تجهيز مختبر منفصل

يمكن استخدام VirtualBox أو KVM أو VMware أو Proxmox، مع شبكة داخلية أو Host-only مخصصة للاختبار. لا توصل آلات الاختبار مباشرة بشبكة تحتوي أجهزة أو بيانات حقيقية.

## قواعد التعامل مع البيانات

قد تنتج الاختبارات ملفات حساسة مثل `pcap` و`pcapng` وKML والسجلات. لذلك:

- لا تضف هذه الملفات إلى Git.
- استخدم بيانات وحسابات تجريبية فقط.
- احتفظ بالمخرجات لأقصر مدة ممكنة.
- احذفها بعد تسجيل النتيجة العامة المطلوبة.
- لا تنشر عناوين IP أو MAC أو إحداثيات حقيقية في Issues أو Pull Requests.

يغطي ملف [`.gitignore`](.gitignore) أنواع المخرجات الشائعة، لكنه لا يغني عن مراجعة الملفات قبل كل عملية Commit.
